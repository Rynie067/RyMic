# Baritone Control UI

**Baritone Control UI 0.2.0-alpha.3** is a standalone Fabric client mod for Minecraft Java 26.2.

The Commands page now reads the live Baritone command registry, including aliases, hidden-from-help commands, and commands registered by compatible add-ons. Select a command to see its own help text, fill the shared command editor, and use Baritone's live argument/subcommand completions. The editor executes commands through Baritone's API rather than sending them as chat messages.

The Settings page lists every player-editable Baritone setting, with search, boolean toggles, parser-backed editing, autocomplete, per-setting reset, and reset-all.

- Open the dashboard with **Ğ** on a Turkish Q keyboard (the physical key immediately to the right of P).
- The key appears in Minecraft Controls as the Baritone Control UI binding and can be reassigned there.
- Requires Fabric Loader, Fabric API, and Baritone Fabric 1.19.0 separately; Baritone is not bundled.
