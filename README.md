# Baritone Control UI

**Baritone Control UI 0.2.0-alpha.2** is a standalone Fabric client mod for Minecraft Java 26.2.

The source archive is stored as Base64 chunks under `archive-b64/`. GitHub Actions reassembles and validates it, builds with Java 25 and Gradle 9.5.1, then attaches the JAR to a GitHub pre-release.

- Open the dashboard with **Ğ** on a Turkish Q keyboard (the physical key immediately to the right of P).
- The key is also listed in Minecraft Controls as the Baritone Control UI binding and can be reassigned there.
- The Settings page exposes every player-editable Baritone setting, with search, boolean toggles, parser-backed editing, autocomplete, per-setting reset and reset-all.
- Requires Fabric Loader, Fabric API, and Baritone Fabric 1.19.0 separately; Baritone is not bundled.
