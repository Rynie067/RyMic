# Baritone Control UI

**Standalone Fabric mod for Minecraft Java 26.2.**

The full Gradle source project is included in [BaritoneControlUI-source.tar.gz](./BaritoneControlUI-source.tar.gz). The GitHub Actions workflow extracts it, builds the mod with Java 25, and publishes the resulting JAR as a workflow artifact and GitHub pre-release.

- Open the in-game dashboard with **Right Ctrl**.
- Requires Fabric Loader, Fabric API, and Baritone Fabric 1.19.0.
- Baritone is a separate dependency and is not bundled into this mod.

See the archive's README for feature details and local build instructions.
